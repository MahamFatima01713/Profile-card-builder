rofile-card-builder
An interactive profile card builder — fill in the form and a personal profile card is generated instantly in the browser. Built with vanilla JavaScript, HTML and CSS.
Features
Form fields: profile picture (image link), name, father's name, age, email, qualification and other info
Form validation — name is required, and the email must be present and in a valid format, with clear error messages under the fields
The profile card is created and displayed as soon as the form is submitted — no page reload
How to run
Just open index.html in your browser, fill the form, and submit.
